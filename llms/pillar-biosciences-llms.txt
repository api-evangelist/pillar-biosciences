Pillar Biosciences is a Natick, Massachusetts molecular diagnostics company (founded 2014)
building targeted next-generation sequencing solutions for precision oncology. Its SLIMamp
chemistry enables single-tube, highly multiplexed PCR library prep from as little as 2.5 ng of
DNA. Its oncoReveal panel portfolio spans solid tumour tissue, liquid biopsy, haematologic
malignancy, BRCA/HRD/methylation and inherited disease. PiVAT (Pillar Variant Analysis Toolkit)
is the secondary-analysis pipeline that turns sequencer output into variant calls and reports.

## What an agent should know first

**Pillar Biosciences publishes no API.** There is no OpenAPI, no Swagger, no GraphQL endpoint,
no AsyncAPI, no gRPC/Protobuf, no WSDL, no MCP server, no A2A agent card, and no developer
portal, SDK or public API reference. This was established by probing every Pillar host on
2026-08-26 (see well-known/pillar-biosciences-well-known.yml for the full probe table).

PiVAT's real integration surface is **files, not endpoints**: FASTQ (paired-end preferred),
BAM, VCF and PDF. A laboratory integrates with Pillar by moving those files, not by calling
an API. The PiVAT application at https://pivat.pillarbiosci.com/ is a React single-page app
behind a customer login; it answers HTTP 200 with the same 1,535-byte HTML shell for any
unknown path, so a 200 from that host is never evidence of a document.

## Deployment and compliance

- PiVAT runs either as a local install (research use only, for LDT settings) or as a cloud service.
- Cloud PiVAT is stated by Pillar to be fully compliant with HIPAA requirements.
- Cloud PiVAT can generate tertiary reports using OncoKB, an FDA-recognized oncology knowledge base.
- Pillar ships both research-use-only kits and a separate IVD product line.
- No trust center, no SOC 2 / ISO 27001 attestation, and no security.txt are published.
